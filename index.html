Compiler Design

Lexical Analysis

Lexical analysis is the first phase of a compiler. It converts the source program into tokens that are used by the next phases of compilation.

  • Identifies lexemes
  • Produces tokens
  • Removes unnecessary spaces and comments

Data Structures

Stacks

A stack is a linear data structure that follows the LIFO (Last In First Out) principle.

  • Push adds an element
  • Pop removes an element
  • Top/Peek checks the top element

Database Management

SQL

SQL is used to create, retrieve, update and manage data stored in relational databases.

  • SELECT retrieves data
  • INSERT adds data
  • UPDATE modifies data
